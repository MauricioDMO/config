# Personal System Config

Repositorio de configuración personal para automatizar y mantener entornos Debian/i3/Zsh, Windows/PowerShell y OpenCode.

Su propósito es reunir bootstraps, módulos y configuraciones reutilizables sin convertir los perfiles de shell en archivos monolíticos. La documentación canónica está en [`/docs`](docs/index.md).

## Mapa breve

- `deb/`: configuración y scripts para Debian, i3, Zsh, terminales, servicios y utilidades como Wine y Thermal Guard.
- `win-main.ps1` y `win/`: bootstrap y módulos de PowerShell para Windows.
- `opencode/`: configuración de OpenCode y sus definiciones de agentes, comandos y skills.
- `.env.example`: plantilla de variables locales; los valores reales se mantienen en `.env`, que no se versiona.

Consulta [`docs/index.md`](docs/index.md) para el mapa completo y los enlaces a las guías.
